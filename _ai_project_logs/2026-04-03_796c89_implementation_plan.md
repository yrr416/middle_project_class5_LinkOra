# 1:1 문의 기능 상세 구현 계획 (업데이트)

사용자 중심의 1:1 문의 시스템과 내역 관리, 그리고 상세 답변 확인 기능을 포함하는 통합 계획입니다.

## 1. '로그인 필수 적용' 알기 쉬운 설명

문의 기능에서 '로그인 필수'는 **"누가 이 글을 썼는지"**를 시스템이 확실히 알기 위한 장치입니다.

- **DB의 연결 고리 (`u_idx`)**: `inquiries` 테이블에는 `u_idx`라는 칸이 있습니다. 이는 `user` 테이블의 고유 번호와 연결되는 '꼬리표'와 같습니다.
- **세션(Session)의 역할**: 사용자가 로그인하면 서버는 그 사용자의 번호(`u_idx`)를 '세션'이라는 주머니에 담아둡니다.
- **기능 작동 방식**:
  1. **문의 작성 시**: 세션 주머니에서 사용자 번호를 꺼내 문의글과 함께 DB에 저장합니다. 그래야 나중에 "이 글은 A님이 썼다"라고 알 수 있습니다.
  2. **내역 조회 시**: 세션 주머니에 있는 번호와 일치하는 글들만 DB에서 가져와서 보여줍니다. (로그인을 안 하면 내 번호가 없으니 내 글도 찾을 수 없게 됩니다.)

## 2. 주요 추가 기능: 문의 상세 페이지

사용자가 작성한 문의 내용과 이에 대한 **관리자의 답변(`i_answer`)**을 한눈에 볼 수 있는 상세 페이지(`inquiry_detail.jsp`)를 추가합니다.

## User Review Required

> [!IMPORTANT]
> - **세션 속성명**: 현재는 임의로 `loginUser`라는 이름을 사용하여 개발을 진행하고, 추후 정확한 명칭을 알려주시면 파일 한 곳에서만 수정하여 즉시 반영할 수 있도록 설계하겠습니다.
> - **상세 페이지 설계**: 문의 제목, 카테고리, 작성일, 본문 내용, 그리고 **관리자 답변 영역**을 구분하여 프리미엄 디자인으로 구성합니다.

## Proposed Changes

### [Backend]
- **VO**: `InquiryVO` (상세 페이지를 위한 관리자 답변 및 일시 필드 포함)
- **Mapper**: 
  - `selectInquiryDetail`: 특정 문의 번호(`i_idx`)로 상세 정보와 답변 가져오기
- **Controller**: `/inquiry/detail/{id}` 경로 추가

### [Frontend (JSP)]
- **inquiry_detail.jsp**: 
  - 문의 내용(질문) 섹션 (Dark Slate Gray 계열 레이아웃)
  - 관리자 답변 섹션 (답변 대기 중일 경우 "답변을 준비 중입니다" 표시)
- **my_inquiries.jsp**: 리스트에서 상세 페이지로 연결되는 링크 추가
