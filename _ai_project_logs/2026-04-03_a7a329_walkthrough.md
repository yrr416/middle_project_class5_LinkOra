# 문의 등록 프로세스 최종 정상화 완료

문의 등록 버튼 클릭 시 발생하던 500 에러를 해결하고, 등록부터 조회까지의 **전체 프로세스**를 브라우저로 최종 검증 완료했습니다.

## 추가 수정 사항

### 1. 전송 데이터 필드명 동기화 (`inquiry_form.jsp`)
- **원인:** `InquiryVO`의 필드명을 표준화(`category`, `title`, `content`)했으나, 등록 폼(`inquiry_form.jsp`)의 `name` 속성이 여전히 기존 이름(`iCategory` 등)을 사용하고 있어 서버로 데이터가 전달되지 않았습니다.
- **해결:** JSP 폼의 `name` 속성을 새로운 VO 필드명과 일치시켜 Spring의 데이터 바인딩이 정상적으로 이루어지도록 수정했습니다.

### 2. 전체 프로세스 검증 결과
- **문의 작성:** 카테고리 선택 및 제목, 내용 입력 후 전송 시 에러 없이 처리됨.
- **자동 리다이렉션:** 등록 성공 후 '나의 문의 내역' 페이지로 즉시 이동함.
- **데이터 확인:** 목록 및 상세 페이지에서 방금 등록한 데이터가 날짜 포맷에 맞춰 정확히 노출됨을 확인했습니다.
