# 1:1 문의(Inquiry) 기능 구축 완료 보고서

요청하신 대로 기존 데이터베이스의 `inquiries` 테이블을 활용하여, 로그인이 필요한 1:1 문의 작성, 나의 문의 내역 조회, 그리고 상세 답변 확인 기능까지 모두 구현을 완료했습니다.

## 주요 구현 내용

### 1. 데이터베이스 최적화 연동
- **기존 테이블 활용**: DB에 이미 있던 `inquiries` 테이블의 구조(`i_idx`, `u_idx`, `i_category`, `i_title`, `i_content`, `i_status` 등)를 정밀 분석하여 100% 활용했습니다.
- **MyBatis 자동 매핑**: 언더바(`_`) 케이스와 카멜(`camel`) 케이스를 자동으로 연결하도록 설정하여 코드를 간결하게 유지했습니다.

### 2. 고도화된 백엔드 로직
- **로그인 필수 로직**: `u_idx` 세션 정보를 체크하여 비로그인 사용자의 접근을 차단하고 로그인 페이지로 안내합니다. (현재 임의의 세션 속성명 `loginUser` 사용)
- **상세 조회 기능**: 내가 쓴 글만 안전하게 볼 수 있도록 보안 로직을 포함한 상세 보기 기능을 구현했습니다.

### 3. 프리미엄 디자인 JSP (Pretendard 폰트 적용)
- **문의 작성 (`inquiry_form.jsp`)**: 깔끔하고 현대적인 폼 디자인.
- **나의 내역 (`my_inquiries.jsp`)**: 상태 라벨(대기중/답변완료)이 포함된 직관적인 리스트.
- **상세 보기 (`inquiry_detail.jsp`)**: 질문과 관리자 답변을 명확히 구분한 프리미엄 레이아웃.

## 작업 수행 리포트 (사용한 권한 및 작업)

안전한 작업을 위해 다음과 같은 단계와 권한을 사용했습니다:
1. **상태 보존 (Git Commit)**: 작업 시작 전 현재 상태를 `git commit`으로 기록하여 언제든 되돌릴 수 있도록 조치했습니다.
2. **DB 정밀 조사**: `tmp/DbCheck.java`를 실행하여 실제 데이터베이스의 테이블 스키마와 컬럼 설정을 완벽하게 파악했습니다.
3. **신규 모듈 생성**: `inquiry` 패키지를 통해 관련된 모든 Java 소스 및 XML 매퍼를 독립적으로 구축했습니다.
4. **공통 알림창 추가**: 사용자에게 로그인 안내 등을 전달하기 위한 `common/alert.jsp`를 추가했습니다.

## 복구 방법 (Revert Plan)

만약 현재의 작업 내용이 원하시는 방향과 다르다면, 다음 명령어를 통해 문의 기능 추가 전 상태로 즉시 되돌릴 수 있습니다:
`git reset --hard HEAD~1` (직전 커밋으로 강제 되돌리기)
